# Riftbound

A dark-fantasy top-down action roguelike prototype designed for Android touch controls and desktop browsers.

## Live game preview

Open **[preview.html](./preview.html)** for the live playable game embedded in a preview page. The preview is the actual game build, not a concept render.

You can also open **[roguelike.html](./roguelike.html)** directly.

## Current playable systems

- Desktop keyboard movement and Android virtual joystick.
- Melee attack and healing action.
- Enemies that pursue and damage the player.
- Procedurally varied dungeon floor and wall layout.
- Torchlight pools, dungeon surface details and dark vignette.
- Animated hero movement and attack feedback.
- Health, XP, level-ups, gold and collectible drops.
- Responsive HUD for phone and desktop.

## Controls

- Desktop: WASD / arrow keys to move, Space to attack, Q to heal.
- Android: left virtual joystick to move, right sword button to attack.

## Development roadmap

1. Replace procedural hero/enemy drawings with original Ragnarok-inspired animated sprite sheets.
2. Expand dungeon generation into connected rooms, corridors, doors and set-piece rooms.
3. Add enemy archetypes, attack telegraphs, class abilities and a boss.
4. Add inventory, equipment slots, item rarity, character classes and persistent progression.
5. Add audio, save data, PWA installation and Android/browser performance testing.

The current preview is a functional gameplay prototype. It is not yet the finished Diablo-quality art pass or a complete RPG.
