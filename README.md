# Riftbound

A dark-fantasy top-down action roguelike prototype designed for Android touch controls and desktop browsers.

## Playable prototype

Open `roguelike.html` in a browser (or serve the repository as a static site):

- Desktop: WASD / arrow keys to move, Space to attack, Q to heal.
- Touchscreen: left virtual stick to move, right attack button to strike.
- Current prototype: procedural dungeon floor and walls, chasing enemies, melee combat, health, XP, level-ups, gold drops and responsive HUD.

This is the first gameplay foundation. Art is currently drawn procedurally; production character, monster, environment and animation assets are a later milestone.
