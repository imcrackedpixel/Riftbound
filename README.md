# Riftbound

A dark-fantasy, top-down action roguelike for Android touch controls and desktop browsers.

## Live playable build

- **[Open the Riftbound preview](https://riftbound-character-test.onrender.com/preview.html)**
- [Open the game directly](https://riftbound-character-test.onrender.com/roguelike.html)

The preview embeds the actual browser game. Render deploys this branch automatically when commits are pushed.

## Current gameplay

- Procedurally assembled dungeon floors with connected chambers and corridors.
- A minimap showing explored floor layout, enemies, player and exit.
- Three enemy archetypes: fast ghouls, heavy brutes and ranged cultists.
- Melee attacks, directional arcane bolts, dodge movement and temporary invulnerability.
- Enemy projectiles and a larger floor guardian every third floor.
- Gold and potion drops, health potions, XP, level-ups and stat growth.
- Torch pools, masonry, floor debris, bones, portal effects and dark vignette.
- Desktop keyboard support and Android virtual joystick/action buttons.

## Controls

| Action | Desktop | Android |
|---|---|---|
| Move | WASD / arrows | Left virtual joystick |
| Melee attack | Space | Sword button |
| Arcane bolt | E | ✦ button |
| Health potion | Q | ♥ button |
| Dodge | Shift | Planned touch action |

## Next development milestones

2. Build a more varied tile and prop library with proper room themes, doors, traps and destructible objects.
3. Add class selection, weapon drops, inventory, equipment and skill progression.
4. Add boss mechanics, elite modifiers, quests, audio and save data.
5. Package as an installable PWA and continue Android/browser performance testing.

This remains an actively developed prototype, not a finished Diablo-scale RPG. The current art is procedural placeholder art; sprite and environment art are a major next milestone.
